3. Agent 初始化建议（面向 better-explore）

  1. 定义调研角色协议：统一输入（主题/约束/评估维度）与输出（摘要、对比表、结论）。
  2. 建立技能分层：候选发现、证据采集、对比评估、报告生成四层技能，避免单一大 Prompt。
  3. 标准化评估字段：复用现有 evaluation-template.md 字段，补充“社区活跃度、维护风险、可迁移成本”。
  4. HTML 报告优先：将调研结果落盘为 HTML，便于团队阅读、分享与二次汇总。

4. 建议落地路径

  • 阶段 1：先沉淀 1 份技能地图（本报告）+ 1 个标准化初始化清单。
  • 阶段 2：将高 Star 资源按主题入库（UI 自动化 / RAG / 多 Agent 协同）。
  • 阶段 3：在 scripts/ 下加入“候选抓取 + HTML 报告生成”自动流程。
